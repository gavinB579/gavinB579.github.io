Cisco Packet Tracer - IPv6 Configuration

This project was more about learning IPv6 than it was about learning how to use Cisco Packet Tracer. It utilized, to a lesser extend, the topology design skills seen in my previous projects, but focused more on the configuration aspects. Using two routers, two switches, and two PC's connected on their own separate networks, I had to learn how to configure IPv6 addresses on the devices. Success for this project was measured by the ability of the two routers to communicate with each other, verified via pinging.

I did not struggle too much with this project. There were parts that were difficult to apply, as our professor stepped away from guiding us through the project and let us apply our knowledge. These parts were mainly the configuration of the device settings and not so much the design of the topology or applying IPv6 functionality. I had to go through trial and error to get the configuration right, but in the end it was not too difficult to get the devices communicating with each other. The IPv6 aspect of this project was simple in nature and not too difficult to understand, as we were actively learning about IPv6 in my networking class and the requirements were simple.
