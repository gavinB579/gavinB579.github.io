Cisco Packet Tracer - Multiple Networks Configuration

Utilizing the skills from all of my previous projects, I was able to configure multiple networks in Cisco Packet Tracer. This project involved 6 different VLANs, 2 switches, and 2 routers. Utilizing gateways, subnetting, trunking, and more, I was able to successfully configure the network so that all devices could communicate with each other. One of the new concepts of this project was modifying the routers to support serial connections and configuring the routing protocols to allow for communication between the two routers. We used default routing and static routing to achieve this.

This project was a very difficult one for me. Trying to configure multiple networks with many different devices was a challenge. It took a lot of trial and error, research, and troubleshooting. Working with the CLI's on all devices was a very confusing and arduous task for me, and I even chose to restart the project halfway through to try and apply my research more efficiently. I learned a lot about networking and a lot of the fundamentals of how networks work, and I am happy with the final result.
