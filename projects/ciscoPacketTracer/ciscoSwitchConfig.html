Cisco Packet Tracer - Switch Configuration

This project was completed as part of a course I took on computer networking. It is the first real project of the series of Cisco Packet Tracer projects, and thus focuses on the basics of switch configuration. In this project, I had to configure a network topology, and then configure the switch in the network to allow for communication between the different devices, all with the end goal of creating a functional LAN. This network configuration had to have at least 5 devices (3 PCs, 1 switch, and 1 router), and it had to be formatted in a specific way. The computers must be hooked up to the switch only, and the switch must be hooked up to the router. The PCs must be able to communicate with each other, and they must also be able to communicate with the router.

I did not struggle much with this project, as I had experience, albeit limited, with Cisco Packet Tracer. My professor provided us with a lot of resources to help us complete the project, including a detailed project description, a video tutorial, and a sample file with the network topology already created. I used all of these resources to complete the project. The most confusing part was likely the CLI configuration. Understanding the different commands and their syntax was a bit confusing even with the resources provided by my professor. It is a trend that continued with the rest of the Cisco Packet Tracer projects, as they all had a CLI configuration component.
